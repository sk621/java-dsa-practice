# Java Programs

A collection of Java programs and Data Structures & Algorithms (DSA) practice problems organized by topic. This repository is created to improve problem-solving skills, strengthen Java programming concepts, and prepare for coding interviews.

## 📚 Topics Covered

- Basic Java Programs
- Pattern Printing
- Arrays
- 2-D Arrays
- Strings
- Searching Algorithms
- Sorting Algorithms
- Recursion
- OOPs
- Backtracking
- Bit Manipulation

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/sk621/java-dsa-practice.git
```

2. Open the project in IntelliJ IDEA.

3. Select the required package.

4. Run the desired program class.
